# Cat Café 12 — Static Website

เว็บไซต์ต้นแบบภาษาไทยสำหรับคาเฟ่แมว 12 ตัว

## เปิดใช้งาน
ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์ได้ทันที

## แก้ไขง่าย
- ข้อมูลแมว 12 ตัว: `script.js` ในตัวแปร `cats`
- สี/เลย์เอาต์: `styles.css`
- ข้อความ เมนู ราคา ที่อยู่: `index.html`

## หมายเหตุ
ฟอร์มสมัคร Cat Club และจองเวลาเป็น demo ฝั่งหน้าเว็บ ยังไม่เชื่อมฐานข้อมูลหรือระบบส่งข้อความ
